How to open your world in Minecraft
  1. Download and unzip the Java world ZIP.
  2. Copy the extracted world folder (the one with level.dat) into %APPDATA%\.minecraft\saves on Windows.
  3. Launch Minecraft Java 1.20.4 or newer, choose Singleplayer, and open your world. Use Creative flight to explore.

For WorldEdit, put the .schem file in its schematics folder, then use //schem load filename and //paste.

Live builds use OpenStreetMap. The sample is a synthetic neighbourhood, included for a reliable offline demo. Photo styling is an approximation.
